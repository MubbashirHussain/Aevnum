## ads.txt

**File**: [`public/ads.txt`](../public/ads.txt)

```
google.com, pub-3526896081279499, DIRECT, f08c47fec0942fa0
```

This authorizes Google AdSense publisher `pub-3526896081279499` as a **DIRECT** seller. Served statically at `/ads.txt`. Required for AdSense compliance and brand protection.

## Sitemap

> ⚠️ **Not implemented**. No `app/sitemap.ts` exists. Next.js App Router supports automatic sitemap generation via `app/sitemap.ts`.

**Recommended implementation** (`app/sitemap.ts`):
```typescript
export default function sitemap() {
  return [
    { url: "https://your-domain.com/", lastModified: new Date(), changeFrequency: "weekly", priority: 1.0 },
    { url: "https://your-domain.com/terms", lastModified: new Date(), changeFrequency: "yearly", priority: 0.3 },
    { url: "https://your-domain.com/privacy", lastModified: new Date(), changeFrequency: "yearly", priority: 0.3 },
    { url: "https://your-domain.com/cookies", lastModified: new Date(), changeFrequency: "yearly", priority: 0.3 },
    { url: "https://your-domain.com/contact", lastModified: new Date(), changeFrequency: "yearly", priority: 0.2 },
  ];
}
```

## Canonical URLs

> ⚠️ **Not explicitly set**. No `canonical` link tags are defined. With two Terms routes (`/terms` and `/terms-and-conditions`), this creates duplicate content risk.

**Recommended**: Add canonical metadata to `app/page.tsx` and all other pages:
```typescript
alternates: {
  canonical: "https://your-domain.com/",
},
```

For `/terms-and-conditions`, set canonical to `/terms` or add a redirect.
